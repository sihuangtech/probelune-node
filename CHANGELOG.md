# Changelog

## 0.1.0 — 2026-10-28

- Outbound-only registration, heartbeat and expiring task leases.
- HTTP, TCP, ICMP and DNS checks; bounded MTR/traceroute diagnostics.
- CIDR policy, pinned DNS dialing, explicit TLS behavior and safe process arguments.
- Idempotent results, persistent offline spool, cancellation and credential revocation.
- Container/systemd deployment and bilingual documentation.
