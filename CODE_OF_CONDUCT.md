# Community conduct

Be respectful, specific and constructive. Critique ideas and code without attacking people. Welcome contributors regardless of background, identity or experience. Do not harass, threaten, discriminate, publish private information, spam, or impersonate others.

Maintainers may edit or remove inappropriate content, close discussions or restrict participation. Decisions should consider context and proportionality. Report conduct concerns privately to maintainers using contact information on the organization profile. Do not publish another person's private information in a report.

These expectations apply to project issues, pull requests, discussions and other official community spaces. This document does not create a support contract or change the software license.
